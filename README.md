## Descripción

Este proyecto consiste en un programa sencillo desarrollado en Python para calcular el total de una compra. Para realizar el cálculo se utiliza una función que recibe dos parámetros: el precio del producto y la cantidad comprada.

La función multiplica el precio por la cantidad y devuelve el resultado utilizando `return`. Después, la función es llamada desde el bloque principal del programa y el resultado se muestra en la consola.

## Problema planteado

En una tienda se necesita calcular cuánto debe pagar un cliente dependiendo del precio de un producto y de la cantidad que desea comprar.

## Funcionamiento

El programa utiliza la función `calcular_total(precio, cantidad)`, donde:

- `precio` representa el valor de un producto.
- `cantidad` representa el número de productos comprados.
- La función multiplica ambos valores.
- Finalmente, devuelve el total de la compra.

## Ejemplo

Si el precio de un producto es de 10 dólares y el cliente compra 3 unidades:

**10 × 3 = 30 dólares**

Por lo tanto, el total de la compra es de 30 dólares.
